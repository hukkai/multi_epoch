# Pilot 360M Configs

These configs are pilot runs that predate the current two-stage experiment
layout. Their results still count toward the first-stage grid when the
hyperparameters match omitted sweep settings.

Use these directories for current experiments:

- `configs/360m_4096l/base/`
- `configs/360m_4096l/sweeps/`
- `configs/360m_4096l/pilot/`
